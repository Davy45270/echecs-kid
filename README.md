# Mes premiers échecs

Une application hors ligne (PWA) pour apprendre les échecs aux petits, pièce après pièce, en français.
Vite et TypeScript, sans aucune dépendance d'exécution. Licence MIT.

```
npm ci
npm run dev      # serveur de développement
npm run build    # typecheck puis build dans dist/
npm run lint
npm test
```

Outillage repris d'Opencadkid. Voir `AGENTS.md` pour les règles du dépôt.
